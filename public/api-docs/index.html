Panduan Cepat Pengujian API (Authorize)
1. Dapatkan Token Buka endpoint POST /api/v1/auth/login di bawah, isi email dan password, lalu klik Execute. Salin data.token dari respons.
2. Klik Tombol Authorize Klik tombol hijau Authorize di bawah, lalu masukkan token pada BearerAuth: <token_sanctum>.
3. Role-Based Permissions Endpoint /api/admin/v1/* memerlukan token akun role admin. Endpoint /api/user/v1/* berlaku untuk semua siswa aktif.
